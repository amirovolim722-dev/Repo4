Политика конфиденциальности

Эта политика описывает работу программы Mailer и публичных страниц с её описанием.

Дата редакции: 13 ноября 2026 г.

Какие данные используются

  • Снимки экрана. Снимок может создаваться автоматически при запуске программы, а также по Shift+1. В него попадает видимое содержимое экрана, включая данные открытых окон.
  • Данные компьютера и письма. Имя компьютера, местное время, адреса отправителя и получателя, идентификаторы письма и сведения о результате отправки.
  • Данные Gmail. Адрес авторизованного аккаунта и данные писем, необходимые для проверки разрешения и ранее выполненной отправки. При проверках Mailer ищет подходящие письма и сверяет заголовки и метки.

Для чего нужны разрешения Google

  • gmail.send — отправка письма со снимком через аккаунт, которому пользователь предоставил доступ.
  • gmail.readonly — чтение профиля Gmail для проверки аккаунта, поиск разрешающих писем и проверка папки отправленных, чтобы уменьшить риск повторной отправки.

Если оператор отдельно включает SMTP с OAuth, эта конфигурация использует область https://mail.google.com/ для авторизации в SMTP. При обычной настройке Gmail API широкая область для SMTP не запрашивается.

Кому передаются данные

Снимок, имя компьютера и время передаются через Gmail на настроенный адрес получателя. Оператор определяет этот адрес и круг лиц, имеющих доступ к полученным письмам.

Если после Shift+1 найдено разрешающее письмо и настроен анализ, Mailer передаёт снимок в OpenAI API. Программа может показать предполагаемый ответ. Токен Gmail и содержимое разрешающего письма в этот запрос не включаются. Автоматический снимок при запуске не направляется на анализ.

Данные, полученные через Google API, используются для описанных функций. Они не продаются и не используются для рекламы. Их использование и передача другим приложениям ограничиваются требованиями Google API Services User Data Policy, включая Limited Use.

Где хранятся данные

Файл авторизации Gmail находится на компьютере, где настроена программа. Его следует хранить в месте, доступном только уполномоченным пользователям. Публичный сайт его не принимает.

Пока отправка не завершена, письмо со снимком может храниться в локальной очереди Windows. По умолчанию содержимое письма в очереди защищено средствами Windows, а срок хранения задачи со снимком — до 24 часов. После подтверждения отправки снимок удаляется из записи очереди. Журнал содержит этапы работы и коды ошибок, без токенов и снимков.

Копии писем в почтовых ящиках хранятся по правилам этих ящиков. Удаление локального снимка их не удаляет. Обработку переданных на анализ изображений регулируют настройки API и политика OpenAI.

Как прекратить работу и отозвать доступ

Чтобы закрыть Mailer, нажмите Ctrl+9. Если установлен автоматический запуск службой Windows, отключите его через администратора. Доступ к Gmail можно отозвать в разделе подключений Google-аккаунта. Для удаления локальных данных обратитесь к администратору; для удаления отправленных копий — к владельцам соответствующих почтовых ящиков.
